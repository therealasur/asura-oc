🩹 ASURA — ABMD Repair Tool

Standalone · Not part of the OC Dashboard Worker · Run only when needed
What this does: recomputes autoBiasMode, rawType, followBias, trailingHigh/Low for a chosen date+instrument from the raw preserved fields already sitting in Firestore (netCeChg, netPeChg, candleHigh, candleLow, spot) — using the current, fixed exit logic — and overwrites just those derived fields. It never touches worker_fixed.js or any other part of your live dashboard. Always run a dry run first.
Step 1 — Sign In
Not signed in
Uses the same Firebase project as the OC Dashboard (asura-journal). Firestore Security Rules require a signed-in user — this is the same account you already use.
Step 2 — Select Date & Instrument
Dry run shows exactly what would change without writing anything. Apply is only enabled after a dry run has completed for the same date+instrument.
